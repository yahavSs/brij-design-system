Brij — Email Signature.
  1. Edit the editable fields in the source HTML: name, title, phone, and the relevant links.
  2. Select everything inside the framed area below (the signature itself, not this note).
  3. Copy with Cmd+C.
  4. Paste into Gmail → Settings → General → Signature (not into a compose window).
  5. Save changes at the bottom of the settings page.
All visual elements are baked PNGs so Gmail cannot strip them. Phone text uses Plus Jakarta Sans where available, Helvetica fallback elsewhere.
